# Breaking Bones

Surgical outcomes and AI research, made digestible. A companion site for the Instagram account @BreakkingBones, by Samer G. Salman and Rohan A. Phadke.

Live site: https://samersalman.github.io/samer-rohan-breaking-bones/

## Editing
- Papers live in `data/papers.json`. See `data/README.md` for the fields.
- A weekly GitHub Action pulls new publications from ORCID and opens a pull request. New papers stay title-only until an author writes and approves a plain-English summary (`reviewed: true`).
- Headshots: add `headshots/samer.jpg` and `headshots/rohan.jpg`.

Educational content, not medical advice.
