# Headshots

Drop two photos here:

- `headshots/samer.jpg`
- `headshots/rohan.jpg`

Square or near-square crops work best (about 600 x 600 px, under 300 KB). Until the files exist, the site shows the placeholder drawings in `assets/headshots-placeholder/samer.svg` and `rohan.svg`. Use exactly these filenames (lowercase, `.jpg`). To use a different format, change the two `src` paths in `index.html`.
